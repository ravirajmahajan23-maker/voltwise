Quick reference

Core concepts

Short reminders for formulas used in the calculators.

Ohm’s law

For a resistive circuit, voltage equals current multiplied by resistance: V = IR.

Three-phase active power

For a balanced system using line values: P = √3 × VL × IL × cos φ.

Ideal transformer

The voltage ratio equals the turns ratio: V₁/V₂ = N₁/N₂, assuming an ideal transformer.
