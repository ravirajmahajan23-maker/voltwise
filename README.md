# VoltWise — Electrical Engineering Toolkit

VoltWise is a responsive, browser-based learning toolkit for electrical engineering students.

## Features
- Ohm's law calculator (voltage, current, resistance)
- Balanced three-phase active power calculator
- Ideal transformer turns-ratio calculator
- Power-factor correction capacitor kVAr estimator
- Formula reminders and educational safety note
- Responsive layout; no login, backend, dependencies, or API keys

## Run locally
1. Download or clone this repository.
2. Open `index.html` in a modern browser.
3. No installation or build step is required.

## Configuration
No environment variables or secrets are required.
